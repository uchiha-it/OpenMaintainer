# Contributing to OpenMaintainer

Thank you for your interest.

OpenMaintainer is currently at the pre-launch / architecture stage, so the most valuable early contributions are:

- architecture review;
- maintainer workflow research;
- sandboxing and security design;
- GitHub integration ideas;
- evaluation methodology;
- documentation improvements.

## Ground rules

- Be precise about what is implemented versus planned.
- Do not fabricate benchmark results, users, adoption, downloads, or contributors.
- Prefer small, reviewable changes.
- Keep human approval in the loop for consequential actions.
- Treat repository content and model output as potentially untrusted.

Implementation guidelines will be expanded once the initial codebase is published.

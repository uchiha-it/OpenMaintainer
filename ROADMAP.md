- Repository structure
- CLI skeleton
- Architecture decisions
- Contribution guidelines
- Basic repository inspection

## Phase 2 — Issue Intelligence
- GitHub issue ingestion
- Issue summarization
- Missing-information detection
- Relevant-file discovery
- Investigation plans

## Phase 3 — Reproduction & Testing
- Controlled execution
- Reproduction workflows
- Regression-test generation
- Evaluation dataset

## Phase 4 — Pull Request Review
- Diff analysis
- Change-risk summaries
- Test coverage checks
- Security-sensitive change warnings

## Phase 5 — Contributor Experience
- Issue decomposition
- Codebase explanations
- Contributor onboarding workflows
- Multilingual experiments

## Phase 6 — Initial Stable Release
- Documentation
- Examples
- Evaluation results
- Public development report
- Next-stage roadmap
